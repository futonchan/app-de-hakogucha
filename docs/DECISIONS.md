# 決定記録・仮仕様一覧

**文書版0.4 / 2026-09-14 / 承認済み要件と初期実装案を区別するための正本**

## 1. ステータスと優先順位

| 記号 | 意味 | 変更の扱い |
|---|---|---|
| R-xx | ユーザーが明言、または具体案を明示採用した要件 | 変更前に確認する |
| P-xx | 助手が提案した、未承認の初期実装案 | 初回実装に使える。変更は理由・影響・テストを記録する |
| 対象外 | このMVPでは作らないもの | 追加は別スコープとして確認する |

ユーザーの最新指示 → R-xx → P-xx の順に扱います。
原作動画・添付画像は参考であり、今回ユーザーが指定した値・ルールを覆しません。
設定資料は`config/mvp-defaults.json`。実装で設定を移す場合も、この区別を維持します。

## 5. 特に試遊で確認する3点

**灰色を揃えて消せるか、上下にも押せるか、落下中の箱を消去対象から除くか**は、
プレイの感触を変える初期案です。CodexはP-05・P-03・P-06として表示・報告し、
テストや関数に閉じ込めます。これらの初期案で試作してから変更できます。

ただしユーザーが原作との厳密一致を新たに求めた場合は、仮案で進めず確認します。
本パックは「原作ルールの完全復元」ではなく「合意したスマホMVP」の仕様です。
